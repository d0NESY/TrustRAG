Shared workspace access - reference annex
CURRENT REFERENCE; named scope only

Controlling reference for shared workspace access. Entry permissions belong to facilities access; financial charges belong to the credential fees annex.
The credential fees annex defines a GBP 16 fee for an after-hours replacement card; the access policy defines entry rights only.
Apply only the activity and conditions named in this annex. An operational guide cannot be used to invent an absent commercial rate, compensation clause or retention term. Where an entity-specific negotiated term is requested, the general policy is not sufficient evidence.
