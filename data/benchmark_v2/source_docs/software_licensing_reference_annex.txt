Software seat allocation - reference annex
CURRENT REFERENCE; named scope only

Controlling reference for software seat allocation. Seat allocation answers entitlement questions. Prices and billing currency remain commercial terms.
The reseller commercial appendix specifies CAD for NOVA renewal invoices; the seat allocation policy contains no currency term.
Apply only the activity and conditions named in this annex. An operational guide cannot be used to invent an absent commercial rate, compensation clause or retention term. Where an entity-specific negotiated term is requested, the general policy is not sufficient evidence.
