Application backup recovery - reference annex
CURRENT REFERENCE; named scope only

Controlling reference for application backup recovery. Restore authorisation and snapshot retention belong to the recovery guide; transfer limits belong to the network annex.
The recovery network annex caps regional restore traffic at 80 Mbps; snapshot retention rules impose no bandwidth ceiling.
Apply only the activity and conditions named in this annex. An operational guide cannot be used to invent an absent commercial rate, compensation clause or retention term. Where an entity-specific negotiated term is requested, the general policy is not sufficient evidence.
